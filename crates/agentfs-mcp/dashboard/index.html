设置.

管理此 daemon 的运行配置，适用于全部工作区。

运行时更新

存储设置

本地模式保存全部版本内容。S3 模式将版本内容同步到远程存储。切换会补齐历史内容，完成后继续使用当前挂载目录。

保存后切换

密钥保存在当前配置文件中，请限制该文件的访问权限。页面不会返回已保存的 Secret Access Key 或 Session Token。修改 Session Token 时请同时填写 Secret Access Key。

本地缓存

后台每 30 秒检查一次。超过容量时，自动清理到设置容量的 75%；磁盘空间不足时也会尝试清理。

保存后生效

此设置管理可重新下载的版本内容缓存。正在使用、尚未上传或固定保留的内容受到保护，实际占用可能超过设置容量。

HTTP 访问来源

允许发送请求的额外页面来源，下一次请求使用新设置。

保存后生效

使用 scheme://host[:port] 格式。同源 Dashboard 和没有 Origin 的 CLI 请求可以访问；所有请求均需认证。
